# Content Slots

DayFlow는 슬롯 기반 아키텍처를 사용합니다. 덕분에 원하는 프레임워크(React, Vue 등)의 UI 컴포넌트를 캘린더 코어 엔진에 직접 주입할 수 있습니다.

이를 가능하게 하는 것이 `ContentSlot` 메커니즘입니다. 코어 엔진은 대부분의 UI 요소에 대해 Preact로 만든 기본 구현을 제공하지만, 애플리케이션 디자인에 맞추거나 특정 라이브러리를 쓰기 위해 이를 교체할 수 있습니다.

## 동작 방식

1. **코어가 슬롯을 정의합니다**: `@dayflow/core` 안에서 특정 UI 영역이 `ContentSlot`으로 감싸여 있습니다. 각 슬롯에는 `generatorName`과 `generatorArgs`가 있습니다.
2. **구현은 여러분이 제공합니다**: `DayFlowCalendar` 컴포넌트에 컴포넌트나 렌더 함수를 전달하면, 어댑터가 코어가 지정한 정확한 위치로 포털을 통해 배치합니다.

## 사용 가능한 슬롯

| 제너레이터 이름                   | 설명                                                                                                                 | 인자                                                                      |
| :-------------------------------- | :------------------------------------------------------------------------------------------------------------------- | :------------------------------------------------------------------------ |
| `colorPicker`                     | 이벤트 색상을 고르는 작은 색상 선택기입니다.                                                                         | `{ color, onChange, onChangeComplete }`                                   |
| `createCalendarDialogColorPicker` | 대화상자에서 사용하는 기능이 풍부한 색상 선택기입니다.                                                               | `{ color, onChange, onAccept, onCancel, styles }`                         |
| `eventContent*`                   | 이벤트 카드의 사용자 정의 렌더링입니다(예: `eventContentDay`).                                                       | `{ event, viewType, isAllDay, isMobile, isSelected, isDragging, layout }` |
| `eventContextMenu`                | 이벤트용 사용자 정의 우클릭 컨텍스트 메뉴입니다.                                                                     | `{ event, onClose }`                                                      |
| `eventDetailContent`              | 이벤트 상세를 열었을 때 팝오버·패널에 표시되는 내용입니다.                                                           | `{ event, isAllDay, onEventDelete, onEventUpdate, onClose, app }`         |
| `eventDetailDialog`               | 이벤트 상세를 열 때 표시할 사용자 정의 대화상자입니다. `useCalendarApp`에 `useEventDetailDialog: true`가 필요합니다. | `{ event, isOpen, isAllDay, onEventDelete, onEventUpdate, onClose, app }` |
| `gridContextMenu`                 | 캘린더 셀·그리드용 사용자 정의 우클릭 컨텍스트 메뉴입니다.                                                           | `{ date, viewType, onClose }`                                             |
| `gridPopupContent`                | 연간 뷰 `grid` 모드의 사용자 정의 팝업 내용입니다(`gridDateClick: 'popup'`일 때).                                    | `{ date, events }`                                                        |
| `mobileEventDetail`               | 모바일용 사용자 정의 이벤트 상세 드로어·대화상자입니다.                                                              | `{ isOpen, onClose, onSave, onEventDelete, draftEvent, app, timeFormat }` |
| `sidebarCalendarColorPicker`      | 사이드바에서 캘린더 색상을 고르는 색상 선택기입니다.                                                                 | `{ color, onChange, onChangeComplete }`                                   |
| `titleBarSlot`                    | 사이드바 제목 표시줄에 추가할 내용입니다.                                                                            | `{ isCollapsed, toggleCollapsed }`                                        |

## 이벤트 콘텐츠

`eventContent` 슬롯을 사용하면 캘린더에서 이벤트가 렌더링되는 방식을 완전히 바꿀 수 있습니다. 다른 슬롯과 달리 이벤트 콘텐츠는 뷰마다 **반드시** 따로 지정해야 합니다. 각 뷰의 이벤트 구조에 맞는 레이아웃을 유지하기 위해서입니다.

### 뷰별 슬롯

| 슬롯 이름                 | 설명                                   |
| :------------------------ | :------------------------------------- |
| `eventContentDay`         | 일 뷰의 시간 지정 이벤트를 대체합니다. |
| `eventContentWeek`        | 주 뷰의 시간 지정 이벤트를 대체합니다. |
| `eventContentMonth`       | 월 뷰의 이벤트를 대체합니다.           |
| `eventContentYear`        | 연간 뷰의 이벤트를 대체합니다.         |
| `eventContentAllDayDay`   | 일 뷰의 종일 이벤트를 대체합니다.      |
| `eventContentAllDayWeek`  | 주 뷰의 종일 이벤트를 대체합니다.      |
| `eventContentAllDayMonth` | 월 뷰의 종일 이벤트를 대체합니다.      |
| `eventContentAllDayYear`  | 연간 뷰의 종일 이벤트를 대체합니다.    |

## 이벤트 상세 대화상자

이벤트 상세를 모달 형태로 보고 편집하고 싶다면 `eventDetailDialog` 슬롯을 사용하세요. 모바일 우선 애플리케이션이나, 복잡한 이벤트 데이터를 위해 더 넓은 공간이 필요할 때 특히 유용합니다.

> **사전 조건**: 대화상자 모드를 켜려면 `useCalendarApp`에 `useEventDetailDialog: true`를 지정해야 합니다. 그렇지 않으면 이 슬롯은 전혀 호출되지 않습니다.

> **대신 끄기**: 직접 만든 대화상자로 교체하지 않고 내장 플로팅 패널만 없애고 싶다면, 슬롯 대신 `useCalendarApp` 설정에 `useEventDetailPanel: false`를 지정하세요.

## 컨텍스트 메뉴 슬롯

`eventContextMenu`와 `gridContextMenu` 슬롯을 사용하면 기본 우클릭 메뉴를 직접 만든 React 컴포넌트로 완전히 교체할 수 있습니다. 두 슬롯 모두 메뉴를 닫는 `onClose` 콜백을 전달받습니다.

- **`eventContextMenu`** — 이벤트를 마우스 오른쪽 버튼으로 클릭할 때 호출됩니다. `{ event, onClose }`를 전달받습니다.

## 연간 뷰 그리드 팝업

연간 뷰가 `grid` 모드이고 `gridDateClick: 'popup'`(기본값)일 때, 날짜 셀을 클릭하면 그날의 이벤트를 나열하는 팝업이 열립니다. `gridPopupContent` 슬롯으로 이 팝업의 본문을 직접 만든 UI로 교체할 수 있습니다.

이 슬롯은 `createYearView`가 **아니라** `<DayFlowCalendar>`의 prop으로 전달해야 합니다. 프레임워크가 렌더링한 노드(React, Vue 등)는 반드시 슬롯 시스템을 거쳐야 하며, 코어 뷰 설정으로 전달하면 Preact가 크래시합니다.

```tsx
import {
  useCalendarApp,
  DayFlowCalendar,
  createYearView,
  ViewType,
  type GridPopupContentSlotArgs,
} from '@dayflow/react';

function renderYearGridPopup({ date, events }: GridPopupContentSlotArgs) {
  return (
    <div className='rounded-xl border bg-white p-3 shadow-xl'>
      <div className='text-sm font-semibold'>{date.toDateString()}</div>
      {events.length === 0 ? (
        <div className='text-gray-400'>No events</div>
      ) : (
        events.map(e => <div key={e.id}>{e.title}</div>)
      )}
    </div>
  );
}

function MyCalendar() {
  const calendar = useCalendarApp({
    views: [
      createYearView({
        mode: 'grid',
        gridDateClick: 'popup',
      }),
    ],
    defaultView: ViewType.YEAR,
  });

  return (
    <DayFlowCalendar
      calendar={calendar}
      gridPopupContent={renderYearGridPopup}
    />
  );
}
```
