# 시작하기

DayFlow에 오신 것을 환영합니다! 이 가이드를 따라 첫 캘린더를 단계별로 만들어 보세요.

## 설치

### DayFlow 스타일 불러오기

**중요:** 애플리케이션에 DayFlow 스타일을 반드시 불러와야 합니다. 다음 import 문을 App 최상위 컴포넌트나 레이아웃 파일에 추가하세요:

```tsx
// In App.tsx or layout.tsx
import '@dayflow/core/dist/styles.css';
```

또는 CSS 파일에서 불러올 수도 있습니다:

```css
/* src/index.css */
@import '@dayflow/core/dist/styles.css';
```

<Callout title="Tailwind CSS를 사용하시나요?">
  기존 스타일과 CSS 리셋이 충돌하지 않도록 `styles.components.css`를 대신 불러오세요:

```css
@import '@dayflow/core/dist/styles.components.css';
@import 'tailwindcss';
```

자세한 내용은 [Tailwind v4 연동](https://calendar.dayflow.studio/docs-ko/guides/theme-customization#tailwind-v4-연동)을 참고하세요.

> **팁:** `create-dayflow` 설치 마법사에서 Tailwind CSS에 "예"를 선택하면 이 import 문이 자동으로 추가됩니다.

</Callout>

    import {

      createDayView,

        views: [createDayView(), createWeekView(), createMonthView()],

## 스타일 커스터마이징

기본적으로 캘린더는 컨테이너의 전체 너비를 차지합니다. 높이를 비롯한 스타일은 CSS로 조정할 수 있습니다. 예를 들어 반응형 높이를 지정하려면 다음과 같이 작성합니다:

```css
.df-calendar-container {
  --df-calendar-height: 760px !important;
  height: var(--df-calendar-height, 760px) !important;
}

@media (max-width: 768px) {
  .df-calendar-container {
    --df-calendar-height: 550px !important;
  }
}
```

**참고:** 이 라이브러리는 날짜와 시간을 처리할 때 최신 [Temporal API](/docs-ko/introduction/events#고급-temporal-api-직접-사용하기)를 사용합니다. 헬퍼 함수(`createEvent`)를 사용하면 Temporal을 직접 다루지 않고도 이벤트를 쉽게 만들 수 있습니다.
